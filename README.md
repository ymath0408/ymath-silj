# Y-MATH 실적관리

에듀OK 재학생명부/퇴원생명부로 강사별 월 실적표를 자동으로 만드는 학원 내부용 프로그램입니다.

- 이 저장소에는 **프로그램 코드만** 있습니다. 학생 명단·실적 금액·에듀OK 비밀번호는 각 PC와 공유 데이터 폴더에만 저장되고 여기에 올라오지 않습니다.
- 프로그램은 켤 때마다 이 저장소의 `version.json`을 확인해서 새 버전을 자동으로 설치합니다.

## 새 PC에 설치

1. 이 페이지의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. 폴더 이름을 `Y-MATH 실적관리`로 바꿉니다. (권장) NAS의 공유 폴더에 두면 4대가 한 프로그램을 같이 쓰고, 업데이트도 NAS 파일만 바꾸면 됩니다.
3. `실적관리 실행.bat`을 더블클릭합니다.
4. 수정 모드를 켜고 **[설정]**에서
   - **데이터 폴더**: 학원 공유 OneDrive 폴더 경로 입력 → [이 폴더로 바꾸기]
   - **에듀OK 연결**: 아이디/비밀번호 저장 → [연결 시험]

## 폴더 구조

| 위치 | 내용 |
|---|---|
| `app.html`, `server.ps1` | 프로그램 (자동 업데이트됨) |
| `local\` | 이 PC 전용: 에듀OK 비밀번호(암호화), 설정, 이전 버전 백업 |
| 데이터 폴더 (공유) | `silj.json` 실적 데이터, `backup\` 자동 백업 |
